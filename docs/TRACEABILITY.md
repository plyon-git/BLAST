# Requirements and verification traceability

This matrix identifies implementation and available synthetic verification. It is not a test-result report. Install `requirements-dev.txt` and run `python -m pytest -q` on the exact release; retain that output with the release commit. Browser checks and the controlled live procedure complement the automated suite. No mocked or synthetic result establishes real carrier behavior.
